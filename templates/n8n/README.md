# n8n(自動化)

「メールが来たら、スプレッドシートに書く」のような、作業の自動化を、画面でつないで作れます。

## 構成と注意

n8n(自動化。ワークフローを作る)。データ(ワークフローと認証情報)は、ボリュームに保存する。

## 変数

| 名前 | 内容 |
| --- | --- |
| `encryption_key` | 暗号化キー |
| `storage` | データの大きさ(MB) |

## 作成後の案内

0. 初めての起動では、データの準備に数分かかります。「接続できません」と出たら、少し待ってから、開き直してください。
1. 公開 URL を開いて、オーナーのアカウントを作ります。最初に開いた人がオーナーになるので、作成が終わったら、すぐ開いて、作ってください。
2. 「暗号化キー」は、保存した認証情報(外部サービスのパスワードなど)を守る鍵です。控えておいてください。失うと、保存した認証情報が読めなくなります。
3. 外部のサービスから、n8n を呼び出す(Webhook)ときは、デプロイの「起動設定」で、環境変数 WEBHOOK_URL に、公開 URL(https://…/)を入れて、反映します。
