# CloudBeaver(データベース管理)

ブラウザで、データベースの中身を見たり、SQL を書いたりできます。PostgreSQL、MySQL、MariaDB など、たくさんの種類につなげます。

## 構成と注意

CloudBeaver(ブラウザで使える、データベースの管理画面。DBeaver の Web 版)。接続の設定とユーザーは、ボリュームに保存する。

## 変数

| 名前 | 内容 |
| --- | --- |
| `storage` | 設定の置き場の大きさ(MB) |

## 作成後の案内

1. 公開 URL を開くと、最初の設定画面が出ます。管理者の名前とパスワードを入れてください。この画面は、最初に開いた人が、操作できてしまうので、作成が終わったら、すぐ、済ませてください。
2. 接続は、「新しい接続」から足します。同じプロジェクトのデータベースには、service の DNS 名(deploy の詳細に出ます)でつなげます。
3. 起動に、1〜2 分かかります。
