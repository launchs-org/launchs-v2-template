# Vaultwarden(パスワード管理)

自分専用のパスワード管理です。Bitwarden のアプリや拡張機能を、そのまま使えます。

## 構成と注意

Vaultwarden(パスワード管理。Bitwarden 互換)。データは、ボリュームに保存する。

## 変数

| 名前 | 内容 |
| --- | --- |
| `signups_allowed` | 新しい登録を許す |
| `storage` | データの大きさ(MB) |

## 作成後の案内

1. 公開 URL を開いて、「アカウントを作成」で、自分のアカウントを作ります。マスターパスワードは、忘れると、中身を取り出せません。必ず、控えてください。
2. 自分(と、使う人)のアカウントを作り終えたら、新しい登録を止めるために、デプロイの「起動設定」で、環境変数 SIGNUPS_ALLOWED を false にして、反映します。
3. Bitwarden のアプリや拡張機能で、サーバーの URL に、この公開 URL を入れて、ログインします。
データは、ボリュームに入っています。ボリュームを消すと、パスワードも消えます。
