# Uptime Kuma(死活監視)

サイトやサービスが動いているかを、定期的に確かめて、止まったら知らせてくれます。状態ページも作れます。

## 構成と注意

Uptime Kuma(サイトの死活監視と、状態ページ)。データ(監視の設定と履歴)は、ボリュームに保存する。

## 変数

| 名前 | 内容 |
| --- | --- |
| `storage` | データの大きさ(MB) |

## 作成後の案内

1. 公開 URL を開くと、管理者のアカウントを作る画面が出ます。最初に開いた人が管理者になるので、作成が終わったら、すぐ開いて、作ってください。
2. ログインしたら、「監視を追加」から、見張りたい URL を入れます。
3. 通知(メール、Slack など)は、右上のメニューの「設定」→「通知」で、足せます。
