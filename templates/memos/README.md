# Memos(メモ)

思いついたことを、すぐ書き留められる、シンプルなメモです。タグや検索もあります。

## 構成と注意

Memos(手軽なメモ)。データは、ボリュームに保存する。

## 変数

| 名前 | 内容 |
| --- | --- |
| `storage` | データの大きさ(MB) |

## 作成後の案内

1. 公開 URL を開いて、最初のユーザーを作ります。最初のユーザーが、管理者になります。作成が終わったら、すぐ開いて、作ってください。
2. 管理者でログインしたら、「設定」で、ほかの人の登録を許すかどうかを、決められます。
