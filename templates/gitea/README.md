# Gitea(Git ホスティング)

自分たちのソースコードを置いて、管理できます。GitHub のような画面で、課題管理やレビューもできます。

## 構成と注意

Gitea(自前の Git ホスティング)。データベースは SQLite(1 つのファイル)。リポジトリと設定は、ボリュームに保存する。
SSH は、インターネットに公開できない(公開は HTTP だけ)ので、無効にする。Git の操作は、HTTPS で行う。

## 変数

| 名前 | 内容 |
| --- | --- |
| `storage` | データの大きさ(MB) |

## 作成後の案内

1. 公開 URL を開くと、最初の設定画面が出ます。「サーバーのドメイン」と「Gitea のベース URL」に、この公開 URL(https://…/)を入れます。ほかの項目は、そのままで構いません。
2. 同じ画面の下の「管理者アカウントの設定」で、管理者を作ります。この設定画面は、最初に開いた人が、操作できてしまうので、作成が終わったら、すぐ、済ませてください。
3. Git の操作(clone、push)は、HTTPS で行います。SSH は、使えません(インターネットに公開できないため)。
