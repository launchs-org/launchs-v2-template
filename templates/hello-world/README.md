# hello-world(自動デプロイの入口)

**CI/CD(GitHub Actions での自動デプロイ)をする場合も、このテンプレートから始めてください。**

最初に置く、仮のウェブアプリ(`traefik/whoami`)です。開くと、ホスト名と、受け取ったヘッダーが出ます。**自分のアプリを、GitHub から自動でデプロイするための、出発点**として使います。

## 構成と注意

deploy を 1 つ(ポート 80)と、Service、公開の ingress を作ります。イメージは、後から、deploy の「自動デプロイ(webhook)」で、自分のイメージに置き換えます。

自分のアプリのポートが 80 でないときは、deploy の「Service」と、ingress の「ルール」の、ポートを直してください。
