# Grafana(グラフの画面)

データベースや監視のデータを、グラフにして見られます。ダッシュボードを作って、共有できます。

## 構成と注意

Grafana(グラフの画面)。管理者のパスワードは自動で作る。データ(ダッシュボードの設定)は、ボリュームに保存する。

## 変数

| 名前 | 内容 |
| --- | --- |
| `password` | 管理者(admin)のパスワード |
| `storage` | データの大きさ(MB) |

## 作成後の案内

1. 公開 URL を開いて、ユーザー名 admin と、下の「作成した値」のパスワードで、ログインします。
2. 最初のログインのあと、パスワードを変えるよう案内されます(変えなくても使えます)。
3. 左のメニューの「Connections」→「Data sources」で、見たいデータ(PostgreSQL、MySQL など)を、つなぎます。同じプロジェクトのデータベースは、その Service の DNS 名(デプロイの「Service」タブ)で、つなげます。
